# Колония — симулятор колонии для Android (в духе RimWorld)

Личный проект для одного игрока, не для публикации. Целевое устройство — Samsung Galaxy S25 Ultra
(экран в CSS-пикселях: 891×412 горизонтально, 412×891 вертикально; 120 Гц).
Игра работает в браузере и ставится на главный экран как PWA.

## Главные принципы

1. **Сначала играбельность, потом красота.** Каждый этап заканчивается тем, во что можно поиграть на телефоне.
2. **Симуляция отделена от отрисовки.** Модуль `sim/` не знает про DOM, Canvas и браузер — только чистый TypeScript.
   Это позволит тестировать логику и при желании позже сменить движок (Godot/libGDX), не переписывая механики.
   **Решение по движку:** основной — веб (TypeScript + Canvas 2D, PWA). Причины: быстрый цикл разработки и тестов,
   мгновенные обновления через GitHub Pages, DOM/CSS удобен для табличного интерфейса, карты 60×60 для Canvas мало.
   Пересмотреть после Этапа 2 (а Capacitor-обёртка в APK возможна без переписывания), если: нужна карта >200×200
   или десятки поселенцев с тяжёлым поиском пути, нужны анимации/освещение/шейдеры, либо PWA начнёт мешать
   (потеря сохранений, тормоза). Тогда — Godot, перенос `sim/` как есть по логике.
3. **Детерминизм.** Всё случайное — через сидированный ГПСЧ (например mulberry32), никакого `Math.random()` в `sim/`.
   Одинаковый сид + одинаковые команды = одинаковый результат.
4. **Фиксированный тик.** Симуляция идёт тиками (20 тиков/с на скорости 1×; 2× = 40, 3× = 60), отрисовка — по `requestAnimationFrame`
   с интерполяцией. Пауза останавливает тики, но не интерфейс.
5. **Маленькие шаги.** Перед крупной фичей — короткий план в чат, потом реализация, потом тесты.

## Стек

- TypeScript (strict), Vite, без фреймворка для игрового поля.
- Отрисовка карты: Canvas 2D (если упрёмся в производительность — PixiJS).
- Интерфейс (панели, таблицы, меню): обычный DOM + CSS поверх канваса. Можно Preact, если станет сложно, но не раньше этапа 3.
- Тесты: Vitest для `sim/`.
- Сохранения: IndexedDB (через `idb-keyval` или аналог).
- PWA: `vite-plugin-pwa`, манифест с `"orientation": "any"`, офлайн-кеш.
- Деплой: GitHub Pages (нужен HTTPS, чтобы PWA ставилась на телефон).

## Структура

```
src/
  sim/            # чистая логика, без браузера
    world.ts      # состояние мира, тик
    map.ts        # клетки, местность, проходимость
    pawn.ts       # поселенец: навыки, черты, нужды, настроение
    jobs.ts       # задачи, приоритеты, выбор работы
    pathfinding.ts# A* по сетке
    build.ts      # чертежи и строительство
    items.ts      # предметы, склады, переноска
    events.ts     # рассказчик и события (этап 4)
    rng.ts
  render/         # Canvas: камера, тайлы, поселенцы, выделение
  ui/             # DOM-панели: верхняя полоса, панель поселенца, таблица работ, меню строительства
  input/          # жесты: тап, долгое нажатие, перетаскивание, щипок
  save/           # сериализация мира, IndexedDB, автосейв
  main.ts
tests/
```

## Механики (целевой объём)

**Карта:** сетка ~60×60 клеток (пока одна карта, без мира). Местность: трава, земля, камень (горы), вода, деревья.
Генерация по сиду (шум для гор и воды, разброс деревьев).

**Поселенцы (3 на старте):**
- Навыки 0–20: строительство, ремесло, добыча, готовка, растения, стрельба, медицина, общение, интеллект.
  Увлечение 0/1/2 — множитель опыта и бонус к настроению за работу.
- 1–2 черты характера (трудоголик, оптимист, ночная сова, обжора…), каждая — модификатор чисел.
- Нужды 0–100: еда, сон, отдых, комфорт (позже — красота, общение). Падают со временем.
- Настроение = база + сумма «мыслей» с длительностью (+10 «вкусный ужин», −8 «видел труп», −5 «спал на полу»…).
  Порог срыва → поселенец временно перестаёт работать (бродит, ест сырую еду).

**Работы:** 11 типов (тушение, лечение, готовка, охота, строительство, растения, добыча, ремесло, переноска, уборка, исследования).
Таблица приоритетов поселенец × работа: 1–4 или выкл.
Поселенец сам выбирает задачу: сначала срочные нужды, затем по приоритету (1 раньше 4), при равенстве — ближайшая.
Игрок напрямую не управляет поселенцами (кроме приказа «иди сюда»), он расставляет приоритеты и ставит чертежи.

**Строительство:** чертёж → переноска материалов → постройка с прогрессом. Стены, двери, полы, кровать, плита, склад-зона, огород-зона.
Комнаты определяются заливкой; «своя спальня» влияет на настроение.

**Время:** день/ночь, 4 сезона по 15 дней, температура по сезону, рост растений.

**Позже (этап 4+):** рассказчик (набеги, странники, болезни, торговцы, холодная волна), простой бой (укрытия, точность от навыка),
ранения по частям тела, лекарства, исследования.

## Управление на телефоне

- Тап — выделить клетку/поселенца/объект. Тап по пустому месту — снять выделение.
- Долгое нажатие (~400 мс) — контекстное меню действий (идти сюда, приоритетно сделать, разобрать).
- Перетаскивание одним пальцем — панорама карты; в режиме строительства — рисование линии стен/прямоугольника зоны.
- Щипок — масштаб (ограничить диапазон). Двойной тап — центрировать на выделенном.
- Все кнопки ≥ 44×44 CSS px. Учитывать вырез камеры и системные отступы (`env(safe-area-inset-*)`).
- Автосейв при `visibilitychange` (сворачивание) и раз в игровой день. Телефон может выгрузить вкладку в любой момент.

## Этапы

Каждый этап завершён, когда: проходят тесты, `npm run build` без ошибок, и это работает на телефоне через GitHub Pages.

**Этап 0 — каркас.** Vite + TS, PWA-манифест, деплой на GitHub Pages, пустой канвас на весь экран,
поворот экрана без поломки, safe-area. Проверка: игра ставится на главный экран S25 Ultra и открывается офлайн.

**Этап 1 — карта и один поселенец.** Генерация карты по сиду, камера (панорама, щипок), отрисовка тайлов,
A* с тестами, тап по клетке → поселенец идёт туда. Пауза/скорости. Цель: 60 fps на карте 60×60.

**Этап 2 — работы и нужды.** 3 поселенца, нужды и их падение, еда (ягодные кусты/запасы), сон на полу,
система задач + таблица приоритетов, добыча камня и рубка деревьев, переноска на склад-зону.

**Этап 3 — строительство и настроение.** Режим строительства с рисованием пальцем, чертежи, стены/двери/кровати/плита,
комнаты, готовка, огород, мысли и настроение, срывы. Панель поселенца (вкладки Нужды/Навыки/Здоровье). Сохранение/загрузка.

**Этап 4 — события.** День/ночь, сезоны, температура, рассказчик с простыми событиями (странник присоединяется,
холодная волна, болезнь, торговец).

**Этап 5 — угрозы.** Набеги, простой бой, ранения, медицина.

## Правила для работы в этом репозитории

- Перед реализацией этапа — короткий план и вопросы, если что-то неясно; потом код.
- Логику в `sim/` покрывать тестами (особенно A*, выбор задач, нужды/настроение, сериализацию).
- Не тянуть тяжёлые зависимости без причины; размер бандла держать небольшим.
- Константы баланса (скорости падения нужд, значения мыслей, опыт навыков) — в одном файле `sim/balance.ts`.
- Тексты интерфейса на русском.
- После каждого этапа обновлять раздел «Статус» ниже.
